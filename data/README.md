# Dados locais

Coloque nesta pasta os JSONs locais necessários para executar o projeto:

- `efeitos.json`
- `extras.json`
- `falhas.json`
- `poderes_prontos.json`

Esses arquivos contêm regras que não podem ser publicadas e são ignorados pelo Git. Para exibir citações, adicione a cada registro uma lista `fontes` com referências conferidas no PDF, como descrito no README da raiz.
